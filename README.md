# Fieldframe

Fieldframe will let people search for images by topic and explore the results in a responsive visual collection. I chose a forest-green and warm-ivory palette to make the interface feel calm and editorial rather than like a generic search page. The large, centered headline gives new visitors a clear starting point, while the topic chips offer quick inspiration without requiring them to invent a search phrase. The results area is an intentionally empty CSS Grid so image cards can be added in Part 2.
